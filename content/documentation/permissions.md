In order to open a file in Oasys you will need to have the relevant permissions.

If you create a patient then you are the owner and have permissions to open and edit all the records for that patient.

{{< middle-section-1 >}}

You can also give others permissions, there is a "Sharing" tab when creating a new record to make this easy. Initially this is populated with a list of people you have given permissions to in the past, so that you don't have to type them in every time.

{{< /middle-section-1 >}}

![](images/oasys_new_record_sharing_2026.png)

If a patient has already been created you can click on "Tools - Manage permissions" to make changes. This opens the window shown below.

![](images/oasys_manage_permissions_2026.png)

If you want to manage permissions for an individual patient, double click on it and add and remove users as desired.

{{< middle-section-2 >}}

When somebody joins your team, you can use the "Share all my patients" button to give them access to everything you have access to.

{{< /middle-section-2 >}}

When somebody leaves your team, they can use the "Transfer my permissions" button to transfer all their permissions to somebody else. This removes their permissions and gives them to another person (if they don't already have them)
